Analyze a prescription image

Uses your Notebook 44 fine-tuned TrOCR model automatically when its checkpoint is mounted. Otherwise runs the explicitly identified Tesseract baseline. Neither engine certifies transcription accuracy.

Image data is processed in memory. The application does not store uploaded images. Do not expose this local research server publicly.

Analyze extracted or typed text

Structured fields are supported. Multiple medicine entries are handled separately. Raw text is not stored. Include labeled doctor, hospital, patient, and prescription details for metadata extraction.

DEMO-DRUG-A is fictional. Its numeric tests must never be used for real medicines.
